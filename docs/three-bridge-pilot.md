# Henry, Morris, and EJE live-source pilot

September 26, 2026. The mile-ordered main page fetches three independent audited source records; an outage in one does not remove bridge rows or another bridge's reading. `npm start` serves `/`, `/api/henry`, `/api/morris`, and `/api/eje`. `npm run pilots:refresh` forces an archived refresh of each feed and prints status, observation time, datum, clearance status and receipt ID. The three stores default to `var/henry`, `var/morris`, and `var/eje`; `HENRY_DATA_DIR`, `MORRIS_DATA_DIR`, and `EJE_DATA_DIR` can set separate persistent paths. Do not run two writers against the same store concurrently. Each downloaded receipt includes raw bodies, hashes, query cutoff, selected reference version, and the computed result. Re-running the pure adapter against `receipt.input` and `receipt.result.asOf` reproduces the result.

Morris USGS metadata pins its instantaneous series identity, 1–30 ft public suppression limits, 72-minute data-gap interval, units, qualifiers, timestamps, and provisional/approved status. It rejects changed source hashes, wrong station or datum, changed zero, wrong metadata, duplicate records, out-of-range values, future times and regressions. Both Henry and Morris report strictly >24-hour lateness, distinct delayed status, exact rational clearance and downward display rounding. Their two-inch allowance is recorded as an owner assumption, never deducted and never represented as an independently verified total error. Gauge-zero epochs and exact foot realization remain unverified; production eligibility is false.

Morris NWPS forecasts use MORI2 HGIFF, LOT, one generated run, a pilot maximum issue age of 18 hours, gaps no greater than six hours, and an explicit 24-hour direction window. The 18-hour limit is a reviewable availability policy for official run intervals, not an owner-confirmed operating limit. A forecast that starts at the next scheduled point within six hours uses that point as its labeled window start; it does not extrapolate to the current time or replace the observed stage. If the forecast is stale, incomplete or absent, its direction is unavailable independently of clearance. EJE has no verified tailwater forecast and the page does not borrow an upper-pool or Morris forecast.

USACE CWMS catalog identifies a separate `IL04.Elev-Pool` series and the `IL04.Elev-Tail` series selected here. The adapter requires the exact tailwater series, location IL04, MVR office, `PT30M`, requested native datum, ft units, one complete response page, strictly increasing timestamp rows and a usable latest quality code. CWMS's 0 quality code is *unscreened*; the page says so. Values are full decimal strings from JSON tokens and **absolute elevation**, so no gauge zero is added. The latest observation time determines DELAYED above 72 minutes and LATE strictly above 24 hours. The 48-hour query window cannot serve as a stale-reading fallback. The connection never computes EJE clearance from an NGVD29 reading.

Direct CWMS `datum=NAVD88` requests did not provide an independently verified conversion record. Location metadata reports NGVD29 and the returned time-series payload did not identify a converted datum or offset. A current local benchmark/epoch transformation, verified units and a review of the tailwater-to-bridge relationship are needed before enabling that calculation. The 2-inch direct-water assumption is recorded for study but is not a datum conversion. In all three rows, the overall under-six-inch accuracy objective remains unverified.

Archived September 26 official payloads in `test/fixtures/morris/` and `test/fixtures/eje/` are deterministic tests, never an offline live fallback. A saved live refresh is date-specific; do not quote its values as current after observation age advances. Tests cover source failures, wrong datum/series, identical-time changes, strict late boundary, separate forecasts, receipt replay, local storage restart and independent HTTP failures. Browser layout needs a local Chromium installation; `scripts/dom-check-directory.mjs` checks DOM interactions without rendering layout.
